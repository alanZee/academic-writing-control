# 句序、句法与衔接：典型原段细读

用于英文拟稿、段落重构及解释“为何这句话放在这里”。来源：[留档 PDF](../assets/li-zhang-2022-confined-cylinder-wakes.pdf)。全篇主要句群功能在[段落地图](paragraph-map.md)，主张关系在[篇章逻辑](argument-architecture.md)。本文件逐句分析摘要、§1.3 P2、§3.2 P1、§5.2、§5.3，并补充§5.5/§5.6的关键句法。其余段落没有逐句语法标注。

需要模型预测→闭环检验、迁移协议或成本段的原句功能时，读[Wang等细读](model-based-paper-analysis.md)；不要把两文不同作者的用语混成单一个人习惯。

以下以中文转述原句内容，短英语片段只作定位与句法识别；不是可直接复制的成文模板。“为何”是阅读分析，不声称作者实际依此构思。S表示原段内句子顺序；缩写中的点、图号、公式号不另计一句。

## 1. 摘要：12句如何压缩整篇论证（p.1）

| 句序 | 语义骨架与句法功能 | 为什么放在此处 |
|---|---|---|
| S1 | This work作主语，studies带研究对象，in order to交代涡脱抑制目的 | 一句确立系统、途径、目标，避免先谈宽泛机器学习趋势 |
| S2 | 控制动作作主语，系表结构说明双射流吹吸 | 立即把“控制”落到具体物理作用，后面读者可理解动作变化 |
| S3 | theme作主语，to investigate how…交代知识如何进入RL | 把应用任务提升为研究主线；这是后面多个发现的选择依据 |
| S4 | First引入分析，两种参考态与参数范围限定方法对象 | 先提供产生物理认识的方式；括号解释稳态流身份，防止与平均流混淆 |
| S5 | It is found that…给敏感区趋势；when从句与范围语限定条件 | 让方法马上产出一项认识，不在摘要扩成方法教程 |
| S6 | Then + we utilise these physical results + to help design | these回收S4–S5，用途从分析转为控制，是摘要的关键铰链 |
| S7 | We find that…给受控状态；where从句联系该状态与抑制结果 | 先说明到达什么物理状态，后续维持控制才有解释对象 |
| S8 | 持续振荡控制作主语，seems necessary，to maintain this… | this直接接S7；情态强度保留“必要性”的证据范围 |
| S9 | RL作主语，比较外部优化；括号限定对方优化时域 | 承担方法比较支线。其“long run”须回查§5.6实际时间窗，不能迁为无限时域保证 |
| S10 | Furthermore + when稳定性进入reward + may become more stable | 条件先置，设计改变和效果配对，回收C0的动态信息分支 |
| S11 | Finally + according to敏感性 + when探针在敏感区 | 对应另一物理信息入口：观测位置；与S10平行，而非由S10推出 |
| S12 | even when少探针 + properly placed，给有条件的资源扩展 | 让最后结果有实践含义；properly条件不能删掉，亦不意味着任意少探针布局都有效 |

**可迁移的结构：** 对象与任务 → 中心问题 → 产生知识 → 使用知识 → 主要发现与条件。样本并非每个方法都讲一次、每个结果都放一个数字；摘要中结果的顺序也不完全等于正文目录顺序。写新摘要时选择最能回答中心问题的证据，不强凑12句。

## 2. 引言定位段：把研究承诺写成因果相连的工作（§1.3 P2，p.5）

| 句序 | 主干、修饰与指代 | 论证作用 |
|---|---|---|
| S1 | 流动物理作主语，will first be investigated | 短句设置先行任务，让读者准备接收下一长句的范围 |
| S2 | we will reproduce… and will also apply…；目的成分分别指验证、结构与动力学 | 一个并列句区分“复现用来验证”和“敏感性分析提供认识”，不把两者都包装成新发现 |
| S3 | These results will serve…；which从句强调核心主题 | These把S1–S2的产出整体打包，作为控制设计的输入，完成物理与RL两线汇合 |
| S4 | In this part… vanilla RL… will first be applied；工况范围限定 | 从原则转到比较基准，使后面“提高”有参照对象 |
| S5 | pros and cons作主语，被动说明分工况分析 | 为比较结果的差异留空间，不预设所有工况一致 |
| S6 | As a comparison；with…as…与括号分别解释敏感性和稳定性的入口；we will show that… | 明确两条知识到设计的映射：空间信息→探针，动态信息→奖励；这比泛称physics-informed更可检验 |

此段的逻辑不是“做了A、做了B、做了C”的项目清单，而是前项产出被后项使用。S3是关键桥；删去它而只保留方法名，段落会丢掉C0。迁移时借鉴这种依赖关系，不能把未来式承诺当成尚未完成工作的结果证明。

## 3. 方法段：从对象区别推到方法必要性（§3.2 P1，p.7）

| 句序 | 结构 | 信息推进 |
|---|---|---|
| S1 | we will conduct… to study… | 先说明本方法产出什么认识 |
| S2 | To linearise前置目的；total states作主语，被动分解 | 引入分析对象，先定义组成再分析性质 |
| S3 | Based on…前置条件；base state can be chosen as A or B；which…respectively命名 | 同一数学槽位可以放两类物理对象，分别固定术语 |
| S4 | mean flow作主语；by time-averaging说明获得方式 | 先处理容易的一类，形成下一句对比基点 |
| S5 | For the base flow, however；when Re越临界为条件；流动经历分岔并变周期 | 对比不是泛称方法困难，而是由动力学解释困难来源 |
| S6 | Thus；steady-state solution cannot be obtained… | 从上一句推出直接时推求解为何不可用，不把因果藏在算法名后 |
| S7 | We use SFD… to damp… via… | 最后给替代方法、目标与途径，读者已知道为什么需要它 |

这里的“为何”可以由局部句序直接看出：先分清稳态基流与平均流，再解释前者的求解困难，SFD才成为有依据的选择。若新稿只有单一参考态或没有该困难，不复制此对比。

## 4. 假说检验如何跨三段闭合（§5.2，pp.17–18）

### P1：两句提出可检验解释

- **S1**以 From figure 12 提供证据入口；when控制开启给条件；one salient feature is that…将回流区拉长放在句末焦点。读者先拿到具体观察。
- **S2**以 This回收观察，用 clue与may保留假说身份；because从句取回Fig.5中SFD基流的长回流区。前后图通过同一物理特征相连，不是相邻图号的机械连接。

若S2直接改成“因此已经证明趋于SFD”，就越过下一段需要完成的判别。这里关键是“相似性为何值得比较”，不是“相似性已证明同一状态”。

### P2：六句让读者知道如何判别

| 句序 | 结构和任务 | 顺序意义 |
|---|---|---|
| S1 | In order to… this hypothesis；we use…；which引出式5.2 | this hypothesis精确承上；公式因任务而出现 |
| S2 | shedding wake flow can be decomposed…；as in给关系 | 解释公式中参考部分与波动部分的物理身份 |
| S3 | To suppress… we can use…；which说明最小化作用 | 从度量转为控制目标，区分测什么与优化什么 |
| S4 | The idea is then…；or列两个参考；that is进一步解释各自获得方式 | 明确比较只在何种参考定义上不同，避免“使用能量”一词含混 |
| S5 | If… can yield r趋零，then…controlled wake converges… | 条件判据先于结果，给读者独立判断的标尺 |
| S6 | time-mean flow is also tested for a comparison | 短句收束对照目的，再进入实际结果 |

### P3：十句把比较结果变成后文选择

| 句序 | 结构/动作 | 对读者接受结论的贡献 |
|---|---|---|
| S1 | Figure 13 shows… | 交代以下判断的共同证据位置 |
| S2 | Using the mean flow…作主语；cannot effectively suppress | 先给第一候选的结果，省去作者主观评价 |
| S3 | The result indicates that… | 把结果转换为状态改变的解释 |
| S4 | Thus…mean flow is not… | 作局部排除；应读作该实验中参考选择的判断 |
| S5 | On the other hand；using SFD…leads to… | 相同语法槽位呈现第二候选，比较关系清楚 |
| S6 | energy is reduced…；which means… | 用P2定义的判据解释“接近参考态” |
| S7 | lift fluctuations… and no shedding… | 加入不同观测通道，避免只靠奖励自证 |
| S8 | It can be concluded that…；by modifying…；which is very close… | 多项证据之后提出状态结论；close限定不是数学严格相等 |
| S9 | 文献作者作主语，similar results | 已有认识作联系，不能代替S2–S7的本研究证据 |
| S10 | Because…；we will use…in the following | 结论转为下一节的方法约定，读者知道之后为何固定SFD参考 |

**跨段衔接的实质：** P1给假说，P2给判据，P3给比较和决策。指代词this、corresponding与in the following分别向后文携带“问题、实验对象、既定选择”。没有这些实体关系，即使添加therefore也不能修补逻辑。

## 5. 一个原段的11句：启动相位、事件与解释（§5.3，p.19）

原 PDF 中这是一个连续段，不能沿 Markdown 的空行切成三个“作者段落”。它内部有测试、观察和解释三个阶段，但阶段数不等于段落数。

| 句序 | 句法及信息结构 | 为何接在这里 |
|---|---|---|
| S1 | The above RL control…；which非限制从句指出t=16任意 | above回接已知设置，附加信息暴露值得检验的自由选择 |
| S2 | We next test…；in terms of将robustness限定为启动相位 | 将上一句的任意性变成明确检验问题，避免泛称全面鲁棒 |
| S3 | Figure 14 shows…；with结构说明三种启动时刻 | 给出比较组和证据位置 |
| S4 | interval作主语；which把0.8映射到约1/3涡脱周期 | 数值有物理尺度，读者知道测试跨了什么相位范围 |
| S5 | Among the three cases前置范围；a general trend is that…；ahead of与when关联升力极值及卷涡 | 由组内共性归纳时机，把控制曲线事件接到物理事件；范围必须跟随判断 |
| S6 | Afterwards；小射流/能量衰减两个并列陈述 | 给出动作之后的响应阶段，使“峰值时机”成为过程的一部分 |
| S7 | Figure 14 also…；at the moments…；which关联卷涡时刻 | 用场图对上一时序解释作空间佐证，also增加的是证据类型 |
| S8 | large blowing作主语，produces…to offset…；which can be considered… | 从观察转到涡量作用解释；后一评价从句保留推断色彩 |
| S9 | This suggests that…；using large flow rates when…作从句主语 | This概括S5–S8，归纳应在何种事件上施加动作 |
| S10 | trained agent作主语；is adaptive…and captures… | 凝练本段控制认识，放在时序与场证据之后才有支撑 |
| S11 | Due to symmetry前置理由；it can be understood… | 给对称性下的延伸解释；不是另一个已展示实验 |

**顺序的作用：** 先把任意启动设置转成问题，再给可比较条件；先读时间信号，再读场图，最后给物理解释和归纳。新稿也可先给简短发现句再展证据，但不能把未检验解释提前写成已证结论。这个段的11句不应成为新段的固定配额。

## 6. 另外两类关键句法：条件判别与比较范围

### 奖励段：条件句把公式翻译成控制偏好（§5.5 P2，p.22）

先由DMD观察提出“能量低时增长率仍可能转正”，再给奖励。式后按稳定、中性、不稳定三种情况解释增长率符号、指数因子与回报方向：读者由此知道公式奖励什么，而不是只接受“enhanced”这个名称。

句法上，For a stable/neutral flow、For unstable flows把条件放在前面；which means解释数学变化的行为后果。然后With such a reward function回收整组规则，转到策略的预期反应。下一结果块才回答效果是否实际出现。因此不能将设计段的will当作已经得到的实验结论。

注意负奖励的方向：不能机械把“乘更大因子”写成更大奖励。迁移时重算自己公式的单调性与符号，借的是“公式—条件—行为”的解释方式，不是本文式子。

### 外部比较段：先对齐目标，再区分积分与局部时间（§5.6 P4，pp.25–26）

段内先讲布局小变，再用同一图引入外部控制。比较句之前交代优化时域、变量与目标；后面先报告外部优化的短时优势，接着区分整个时域的积分目标与某一时刻的能量值，最后指出RL在较后时刻的局部优势。

This consideration指引入对照的目的；since承担作者对短时优势的解释；Nevertheless开启不同评价层次；For example用图中t=30把后一个判断落到具体位置。比较的主线是**指标/时域如何定义优势**。样本对“最优”“long-term”的措辞不能自动升级为全局优化证明或无限时域性能。

## 8. 形成自己的句子时保留什么

- **保留旧信息到新信息的推进。** 句首常取前句已有对象；句末放本句新增的状态、结果或问题。下一句再取回该信息，形成可追踪链。无需每句以This开头。
- **主句承担本句判断。** 条件、比较和必要定义放从句或介词短语；若关键科学判断被埋进多重括号，重新组织主句。
- **切换主语对应切换职责。** we说明选择；物理量说明观测；figure定位证据；this result/this trend开启解释。避免全篇只用we或只用被动。
- **情态与因果词对应证据。** may、suggests、because、therefore各自承担不同强度。is consistent with需要真实的相符依据，也不能遮盖会改变结论的竞争解释。
- **允许长段，控制任务漂移。** 样本长段的优势是完成一项判断的闭环；新稿若在一个段中更换对象、评价标准或主问题，可拆段并显式交接。
- **继承推理，修正表达。** 原文局部的重复、语法错误、探索记录、过强泛化不必模仿。论证深度来自可区分的对照与明确的物理含义，不来自句长、术语密度或强调词。

写完后做一次简短反向检查：每句是定义、选择、观察、解释、结论中的哪一种；解释前有哪些前提；指代能否唯一回溯；结论比前文证据多走了哪一步。只修真实断点，不为了满足固定序列重写有效段落。
