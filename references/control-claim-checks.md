# 控制论文的主张检查

只检查当前文字实际涉及的主张；这不是每次写作前必须补做的实验清单。下列判据是写作时避免概念漂移的辅助规则，结合[样本画像](source-profile.md) O3、O5、O7–O14 的具体教训制定，并由[双文献对照](cross-source-synthesis.md)补充模型、迁移与成本边界；不是对样本全部科学结论的独立认证。

## 1. 用最小证据记录约束当前文本

已有项目 ledger 时复用，不另建一套。完整章节可在工作上下文中为重要主张记录：

| 主张 | 证据对象/位置 | 工况与比较 | 指标与参考 | 支持范围 |
|---|---|---|---|---|
| 要写入的具体观察或解释 | 作者提供的结果、图/面板、可访问的处理文件或已核验来源 | 参数、开关状态、时间窗、重复/样本信息若有 | 定义、标度、平均或波动、参考状态 | 直接观察 / 对照支持 / 待检验解释 / 仅计划 |

不得填不存在的样本数或文件。用户提供的事实可作为写作输入，但应区分“按提供材料拟稿”与“独立验证了实验”。只有用户要证据审计时才扩大核查到相应原始或处理材料。

## 2. 容易写过头的主张

| 当前证据 | 可以写什么 | 不能仅凭它写什么 |
|---|---|---|
| 平均阻力降低 | 对所测工况的平均阻力变化 | 涡脱消失、升力波动消失、净节能 |
| 控制开启时幅值减小 | 测得振荡/误差受到抑制 | 无控制系统稳定、全局/渐近稳定 |
| 定义明确的状态距离变小 | 在该度量、区域和时间窗接近指定参考 | 两流场完全相同、所有变量收敛 |
| 对定常参考的适用线性分析 | 该参考与模型下的局部线性结论 | 任意时变反馈闭环、非线性全局稳定 |
| 有效窗口中的 DMD 诊断 | 该数据、模式和窗口的模态估计趋势 | 缺模态窗口中的增长率、完整闭环稳定性证明 |
| 时变动作换为一个常数后响应增大 | 该恒定输入在此比较中未维持原响应 | 全部恒定输入无效、等同于关断所有控制 |
| 动作幅值减小 | 控制命令或执行器输出幅值降低 | 功率或净能耗一定降低，除非已有相应度量 |
| 特定探针布局表现较好 | 该布局在对照条件下优于所测布局 | 证明全局最优、结构敏感性等于可观测性 |
| 更换参数后重新训练且效果良好 | 该方法在重训后的工况可用 | 同一策略零样本泛化或参数鲁棒性 |
| 数个噪声/启动相位测试成功 | 所测扰动或相位下的响应表现 | 所有噪声、初始状态或现实环境均鲁棒 |
| 奖励/训练损失趋于稳定 | 训练过程的该项变化 | 独立测试表现、真实控制目标已达到 |
| 新路径在少观测/简单目标下成功 | 所测组合达到指定标准；可界定相同范围内某配置的绝对必要性 | 唯一原因是优化路径、所有旧路径必然失败、无需其他训练信息 |
| 替代模型在给定输入下预测误差较低 | 指定数据、变量与预测时域内的模型表现 | 模型内学到的控制律必然在原系统有效、长时闭环稳定 |
| 在替代环境获得策略，并回到CFD求解器测试 | 原数值系统中的闭环控制效果 | 已经在实验装置或真实工程环境验证 |
| 每步、每episode或推理耗时更低 | 所测计算环节、任务量和硬件下的耗时变化 | 含数据采集、模型训练、适配和验证的端到端加速倍数 |
| 模型误差较高且策略表现较弱 | 两者在所测案例中的共同变化，可提出解释 | 已隔离误差作用，证明它是性能下降的唯一原因 |
| 迁移后再训练优于某一从头训练策略 | 该初始化/重训协议及工况下的比较 | 零样本泛化、所有工况均优于从头训练 |
| 训练时有模型/梯度，部署时用少量传感器 | 部署观测需求的变化及训练前提 | 整个方法的信息需求都更低，或物理可观测性不再重要 |

若当前材料确有更强的理论或实验支持，可以据此升级措辞，但要说明适用对象与条件。避免把上表误用为对所有强结论的禁令。

## 3. 比较前锁定的含义

- **指标：** reward、objective、test metric 是否同一个量；是点值、均值、均方根、积分还是平方和；是否带面积/体积权重；参考状态是什么。
- **时间：** 求解步、控制步、训练长度、优化时域和评价时域是否不同；时间单位与无量纲基准是否相同。
- **资源与信息：** 执行器幅值/频宽、观测量、传感器数量、可用模型、是否重训和计算预算是否相当。未对齐时准确界定比较，不能虚构公平性。
- **信息阶段：** 分开策略部署输入、优化器训练信息与目标计算信息。损失测点不自动等于策略观测点；历史测量、动作历史及内部记忆也属于可用信息。讨论优化路径与需求来源时，按[研究逻辑](research-logic.md)区分可行性、路径依赖和机制归因。
- **模型与迁移角色：** 分开模型训练、策略训练、评价系统；标明直接迁移、目标工况从头训练、迁移初始化后再训练或在线适配，不能统称泛化。
- **成本边界：** 单步/episode吞吐、达到同一目标的策略训练时间和端到端成本分别报告。若声称后者，纳入实际发生的数据生成、建模、优化、适配和验证；摊销或排除的已有成本说明范围。
- **选择：** best seed、单个训练策略、多次独立训练或重复评价的关系；可确认时说明选择规则，不将单次轨迹误写成统计结论。
- **符号：** 参考速度与时间尺度、几何尺度、总量/扰动量一致。流量符号与坐标速度方向由喷口法向及定义决定，不能仅凭上下两个喷口就猜测。

这些项目按当前主张选用。若只是语法润色且输入未含这些细节，保留原意并指出真正影响含义的歧义，不强迫用户补整套协议。

## 4. 缺口和不利证据怎样处理

先确定缺口影响哪一句：数值不明时不补数；机制未检验时保留假说等级；关键对照未做时不生成“已优于”结论。继续处理有充分输入的句段，将缺项写在正文之外的简短说明中。

重新界定贡献必须忠于完整证据和选择规则。不能悄悄排除不利工况、改变评价窗或删掉对照优势，使读者产生与证据不符的印象。用户仅要求润色时，发现实质错误应指出并给出保持可支持含义的改写，不能未经说明改动科学结论。

## 5. 交付前的短审查

逐句问：

1. 这句话在说系统、控制器、数据还是作者推测？对象是否准确？
2. 数字、参考、开关状态、比较方向与输入是否一致？
3. 图或数据支持观察，还是也支持所写解释？
4. 工况、时间窗、训练/重训条件是否被修辞抹掉？
5. 同一结果在摘要、正文、图注、表格与结论中是否使用相同的基准、平均窗、数值与策略身份？冲突先回原始材料核对，不择取更有利数字。
6. 删除方法名后，读者是否仍能看出本段回答的控制问题？

风格验收与科学核验分别报告。规则和有限写作小样通过，不能宣称论文已经复现、通过同行评审或符合所有现行投稿要求。
