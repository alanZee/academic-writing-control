# 核心主张与篇章编排：如何安排，为什么这样安排

用于大纲设计、章节重构和深度风格对标。依据[留档 PDF](../assets/li-zhang-2022-confined-cylinder-wakes.pdf)的摘要、§§1–6、附录 A–D。页码指该稿的印刷页码；版本信息见[来源画像](source-profile.md)。逐段定位见[段落地图](paragraph-map.md)，句序与句法见[句子和衔接细读](sentence-and-transition-analysis.md)。

**本文件解释源论文的具体结构。** 新稿先按[研究逻辑](research-logic.md)确定科学问题、新知识目标及证据安排；“先产生物理认识，再用于控制设计”不是通用先决顺序。其他研究可以通过方法比较、机制检验或适用范围分析产生新认识。

**证据标签：**“明示”表示作者直接说明目的或关系；“可观察”表示文本、图号、比较或先后次序可回查；“解释”表示本分析对其阅读功能的推断。以下所有“为何”“换序影响”和迁移建议均属解释，不代表作者自述写作心理，也不主张这是唯一正确编排。

与方法替代/效率论文的不同组织方式对照时，读[双文献综合](cross-source-synthesis.md)；本文件的C/K编号仅属于Li–Zhang样本。

## 1. 先辨认论文究竟要让读者接受什么

**明示主旨 C0：** 如何利用并嵌入流动的稳定性、敏感性信息，理解和设计受限圆柱尾流的 RL 涡脱抑制控制。摘要 p.1 的 theme、§1.3 p.5 的 primary aim/core theme，以及§6开头 p.27 三次明确这一定位。

**可观察的实现：** 本文先产生物理认识，再把认识用于参考状态解释、动态奖励和空间观测设计，最后以控制比较检验其用途。把它概括为“RL 能控制圆柱”会丢失主要贡献；把它概括为“RL 全面优于其他控制”又会超过实际比较。

以下编号是本分析的导航标签，不是原文编号。每项均指作者在本篇范围内提出的认识，并非本 skill 为其科学正确性作独立认证。

| 标签 | 待建立的认识 | 直接证据/论证所在 | 对 C0 的作用及边界 |
|---|---|---|---|
| K1 物理基础 | 稳态基流、平均流对应不同稳定性对象；敏感区域随参数改变 | §§4.2–4.4，Figs 4–10，pp.10–16 | 提供“可用的信息”；验证部分复现已有结果，不能全算新发现 |
| K2 控制目标状态 | 所测控制趋近 SFD 稳态基流，而非把时间平均流直接当目标 | §5.2，Fig.13，pp.17–18；调用 Fig.5 | 解释有效奖励的参考状态；不是任意系统的普遍目标 |
| K3 时序与维持 | 大动作与卷涡事件关联；随后小幅时变控制维持接近不稳定基流的状态 | §§5.3–5.4，Figs 14–17，pp.19–22 | 解释“如何控制、为何仍需作用”；恒定替换测试与撤除控制测试须区分 |
| K4 动态信息进入目标 | 将增长率信息引入奖励，在所测较高 Re 工况减弱失稳 | §5.5，Fig.18，pp.21–24 | 直接实现 C0 的奖励分支；结果有工况差异，不是稳定性保证 |
| K5 空间信息进入观测 | 覆盖 wavemaker 的探针布置可提供有效设计启发，稀疏时仍依赖具体分布 | §5.6，Figs 19–22，pp.24–27、31 | 直接实现 C0 的观测分支；启发式位置不等于全局最优或严格可观测性定理 |
| B 比较与适用性 | 相位、噪声、布局、参数和外部控制比较，分别检验不同维度 | §§5.3–5.6；附录 C、D | 加强/界定 K2–K5；外部优化为有限时域比较，不能替代核心物理知识贡献 |
| V 可信计算与可解释定义 | 方程、尺度、离散、稳定性对象及网格/外部结果对照 | §§2–3、§4.1及§4.2 | 支撑上述论证的前提；本身不直接证明控制有效 |

## 2. 大纲为何分成这些部分

| 原始安排 | 读者进入时仍需解决的问题 | 本部分交付给后文什么 | 为何放在这里；可替代安排 |
|---|---|---|---|
| §1开头，pp.1–2 | 为什么选这个系统，又为什么讨论 RL？ | 系统、控制任务与物理知识主题 | 先形成共同对象，后面两条文献线才不会游离；短稿可压缩 |
| §1.1，pp.2–3 | 哪些尾流物理与控制有关？ | 分岔、基流/平均流、敏感性与 wavemaker | 为后面的诊断对象建立语义；不是完整圆柱文献史 |
| §1.2，pp.3–5 | RL 已经做到什么，物理知识还能怎样进入？ | 从流动 RL 到物理信息学习，再收窄到稳定性/敏感性缺口 | 两条综述线在这里相接。若只列算法先进性，C0 的物理主题会失去动机 |
| §1.3，p.5 | 本文到底怎样回答这个缺口？ | 目的、比较路径、章节路线 | 把文献问题转为本文可执行的论证承诺，再给目录导航 |
| §2，pp.5–6 | 控制对象、标度、边界与执行器是什么？ | 后文所有比较的共同定义 | 读者先理解物理问题，再进入求解工具；避免在结果中反复补定义 |
| §3，pp.6–10 | 每一种结果如何得到？ | DNS → 参考状态/特征值 → adjoint/wavemaker → RL输入输出与奖励 | 工具存在依赖：敏感性使用直接/伴随模态，RL使用这些信息。可将标准推导移附录，但正文保留概念区别 |
| §4，pp.10–16 | 这个受限系统有哪些可用于控制的物理信息？ | 可信工况、目标状态的动力学、敏感区域 | 使§5的设计有事先依据。也可采用“每个物理发现紧跟对应控制实验”的交织结构，但须保留信息到设计的关系 |
| §5，pp.16–27 | 这些信息是否能解释并改善控制？ | 目标状态、作用时机、维持条件、奖励与探针比较 | 先让控制过程成为可理解对象，再评价两个物理信息入口 |
| §6，pp.27–29 | 读者应带走哪些认识，适用于哪里？ | §6.1物理认识、§6.2控制认识，回扣 C0 | 双分支结论对应双分支成果，避免只复述算法指标 |
| 附录 A–D，pp.29–31 | 如何追溯代码、诊断、外部对照和补充工况？ | 复现与扩展细节 | 减轻主线负担；关键结果的含义仍在正文解释 |

**引言不是三段模板。** 原 PDF 的引言总引导段、§1.1三个段、§1.2两个长段、§1.3三个段，承担不同任务。“物理背景—学习方法—本文定位”是论证层次，不能当成三个排版段。

## 3. Results 的依赖关系：主干与支线

可观察的跨节回指形成以下关系；箭头表示知识被后文使用，不表示所有实验按此时间顺序实施。

```text
§§2–3 定义与方法 → §4.1/§4.2 验证、参数域
                         ↓
          §4.3 基流/平均流关系       §4.4 空间敏感区
                    ↓                     ↓
§5.1 受控流的线索 → §5.2 参考状态检验      §5.6 探针设计比较
                    ↓                     ↑
          §5.4 时变控制的维持作用          │
                    ↓                     │
          §5.5 失稳诊断 → 奖励设计         │
§5.3 相位/事件时序 ──解释启动阶段           │
§5.1 已使用覆盖敏感区的探针 ──前指§5.6解释选择
```

### §4：先确定“在哪个区域研究”，再确定“研究什么状态、什么位置”

- **§4.1 → §4.2：** 网格/域比较为数值结果提供使用依据；临界曲线同时与文献对照并限定后续要抑制的涡脱区。验证并非与故事分离的手续，它产生后文的工况选择。
- **§4.2 → §4.3：** 临界点回答何时开始失稳；平均流分析接着回答涡脱形成后频率和饱和状态如何理解。发生条件与饱和状态分开，避免混淆稳态基流和平均流。
- **§4.3 → §4.4：** 频率/增长率之后转向空间敏感位置，将“系统如何振荡”转成“观测应该看哪里”。§4.4段末明确连接探针布置；这是物理分析兑现控制用途的桥。

### §5：先解释受控状态，再把两个物理知识入口具体化

| 小节 | 局部论证链与主张 | 编排动因与删改/换序影响（解释） |
|---|---|---|
| §5.1，Figs 11–12 | 总动能奖励 → 训练/评估 → 抑制但仍有涡脱、回流区拉长 | 提供§5.2的实际线索，使后文参考状态选择有问题来源。新稿可用最终方法的中性对照呈现，无需复制探索日志措辞 |
| §5.2，Fig.13 | 回流区与 Fig.5 相似 → 近 SFD 基流假说 → 定义距离/奖励 → 两参考比较 → 采用 SFD 参考 | K2 是理解后续“维持不稳定状态”的前提。提前只宣布新奖励最好，会减少其物理解释；假说在这里不应取代比较证据 |
| §5.3，Fig.14 | 任意启动时刻 → 三相位测试 → 动作峰与卷涡事件对齐 → 作用时机解释 | K3 的启动分支和 B 的有限相位检验。放在§5.4前可形成启动/维持的时间顺序，但移到§5.4之后也可成立 |
| §5.4，Figs 15–17 | 目标基流不稳定 → 小幅时变动作是否重要 → 恒定替换 → 时序/模态证据 → 噪声检验 | 从“效果很好”转向“为何还要持续控制”；为§5.5将增长率加入目标提供动机。噪声段扩展维持问题，并不证明所有干扰鲁棒性 |
| §5.5，Fig.18 | 较高 Re 困难 → 低能量仍可能失稳 → 增长率惩罚 → 比较效果 → 物理解释 | K4 直接完成动态信息的设计转化。若先给公式再给诊断，奖励容易显得经验拼接；可压缩前面诊断，但不要删除其依据 |
| §5.6，Figs 19–22 | 初始布点问题 → 敏感区假说 → 区域比较 → 布局/外部对照 → 参数变化 → 少探针边界 | K5 完成空间信息的转化。先建立区域原则，再讨论布局细节，可分清原则与具体最优点；外部算法比较是同图中的支线，不是全节唯一目的 |

**不应硬讲成单线：** §5.6主要承接§4.4，可与§5.5换序；§5.3不是奖励设计的必备前提。§5.1甚至提前采用了§5.6才论证的探针布置，作者用显式前指管理这一依赖。因此可借鉴的是解释顺序和回指方式，而非绝对禁止前指。

## 4. 细到段落时，“为什么”应问什么

用[段落地图](paragraph-map.md)定位相似任务。先看前段留下什么认知状态，再判断本段贡献：新增定义、提出可检验解释、提供比较、排除一种解释、限定适用范围，或将发现转成设计选择。

例如§5.2的三个段形成完整的读者接受过程：

1. **看到相似性。** 承接§5.1的回流区变化，跨节取回§4的 SFD 图。此时读者获得的是值得检验的假说。
2. **知道什么观察能判别。** 先定义相对参考态的量，再说明两个参考与接近零的含义。读者可据此评价下一段，而非只能接受作者结论。
3. **获得结果并理解后果。** 同段依次写平均流比较、SFD 比较、升力/场图佐证、状态结论、文献关联与后文选择。最后的选择已经由前面证据挣得。

若把结论和“后文都用 SFD”移到开头，只要改写成待检验假说也能成立；若仍用已证实语气，就把论证责任提前了。换序分析的目的在于识别需要补偿的解释，不是禁止任何不同写法。

## 5. 迁移到新稿：先设计论证，再借句式

在工作上下文中形成以下精简映射即可；用户未要求时不额外生成流程文件。

1. **中心句：** 在什么系统、工况与控制目标下，本文要建立什么认识？区分方法贡献、物理解释与工程表现。
2. **主张依赖：** 每项认识需要哪些定义、基线、对照和解释？哪些只是适用性支线？新稿没有稳定性/敏感性分析时，用真正已有的动力学或控制证据替代，不能造出同款物理主线。
3. **章节交接：** 给每节写一句“本节产出 X，后文用它判断/设计 Y”。产出不被使用时，考虑压缩、移位或重新解释其独立贡献。
4. **段落安排：** 每段确定一个中心判断，可容纳多个相互依赖的论证动作；先决定读者何时需要证据，再决定是否拆长段。
5. **句序安排：** 已知对象接到新增信息；方法句交代判别条件，结果句给观察，解释句承担相称推断。避免连接词存在而前提缺席。
6. **反向检查：** 从结论回查 Results、再回查引言承诺；没有证据的承诺不能通过“像样本的措辞”获得支持。重要主张的改变按当前用户授权处理。

最终迁移的是“各部分共同建立中心认识”的连贯性。样本表现为物理认识被用于设计；其他论文可表现为新方法与比较促成知识发现。节数、段长、公式数量、实验名称和探索顺序均按新稿内容决定。
